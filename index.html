Conecta tu base de datos

EduControl guarda todo en Firebase Firestore (plan gratuito Spark). Pega aquí la configuración de tu proyecto.

1. Entra a console.firebase.google.com y crea un proyecto (gratis).
2. Dentro del proyecto, ve a Compilación → Firestore Database y crea la base de datos (modo producción, cualquier región).
3. Ve a Configuración del proyecto → Tus apps → Agregar app Web (ícono </>).
4. Copia los valores de firebaseConfig y pégalos arriba.
5. Importante: en Firestore → Reglas, configura reglas de seguridad antes de usar el sistema en producción real (por defecto queda abierto para pruebas).
